# Reader：本地电子书阅读工作台

输入一本书的名称，或提供 EPUB、PDF、HTML、TXT、DOCX、扫描件和页面照片，`$reader` 会获取或整理可用书籍资料，并生成一个数据全部保存在本地的 HTML 阅读工作台。

阅读器支持目录与搜索、阅读进度、持久高亮、取消高亮、波浪线批注、页边笔记、显示设置、JSON 备份恢复和 Markdown 笔记导出。
